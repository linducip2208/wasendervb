1. Mulai cepat

  1. Buka fitur yang dipakai (mis. Bulk Sender), klik Start untuk membuka browser WhatsApp, lalu scan QR dari HP sampai status Initialised.
  2. Tambah kontak: ketik manual, Import Excel (kolom pertama = nomor, kolom berikutnya = nama/variabel), atau ambil dari Contact List Grabber.
  3. Tulis pesan, atur jeda, klik Start. Pantau kolom Status di grid: Success = terkirim.
Nomor ditulis format internasional tanpa +/spasi, mis. 6281234567890. Gunakan Number Filter dulu untuk membuang nomor yang tidak aktif.

2. Spintax — variasi pesan otomatis

Spintax memutar kata/kalimat agar tiap penerima dapat versi berbeda (mengurangi risiko terdeteksi spam). Formatnya:

{variasi1|variasi2|variasi3}

Contoh:

{Selamat siang|Selamat pagi|Selamat malam|Halo|Hi} kak, {promo|diskon|penawaran} spesial hari ini!

Sistem memilih 1 variasi secara acak setiap kirim. Aturannya:

  • Wajib dibungkus kurung kurawal { } dan dipisahkan pipe |.
  • Bisa nested (bersarang): {Hi|Halo} {Bapak|Ibu} {{nama}}.
  • Berlaku di pesan teks dan caption gambar/file, untuk pengiriman single, grup, broadcast, dan auto-reply.
  • Format lama {{ KEY :a|b }}, {{ RANDOM }}, dan {{sys.date}} tetap didukung.
Tanpa { } teks dikirim apa adanya — itu sebabnya spintax yang ditulis polos "tidak jalan".

3. Time interval / jeda antar pesan

Jeda diatur di form pengiriman (Bulk Sender single & grup):

  • Delay after every message (From–To, detik) — jeda acak tiap pesan, mis. 3–15 detik. Makin besar makin aman, makin lambat.
  • Delay after N messages — istirahat panjang tiap N pesan terkirim, mis. tiap 50 pesan istirahat 120–300 detik.
  • Daily limit (General Settings > Anti-Ban) — batas pesan per akun per hari, default 500. Jika limit tercapai pengiriman berhenti otomatis dan lanjut besok.
  • Skor kesehatan WA — di bawah batas (default 40) pengiriman diblokir otomatis sampai akun pulih. Lihat di menu Ringkasan Hari Ini.
Akun baru: mulai 20–30 pesan/hari, naikkan bertahap tiap minggu (warm-up). Jangan kirim template yang 100% sama — kombinasikan dengan spintax.

4. Menyebut nomor & nama (banyak kontak)

Personalisasi pesan pakai variabel dari file Excel. Kolom pertama = nomor HP, kolom berikutnya bisa dipakai sebagai variabel:

62812xxxxxxx | Budi
62813xxxxxxx | Siti

Lalu di pesan tulis {{nama}} (nama kolom, huruf kecil). Contoh pesan:

{Selamat siang|Halo} {{nama}}, ada promo khusus buat kamu hari ini.

Hasil untuk Budi: "Selamat siang Budi, ada promo khusus buat kamu hari ini."

  • [NAME] dan [SPOILER] — variabel bawaan, bisa disisipkan lewat tombol key-marker di form pesan.
  • Variabel custom lain mengikuti nama kolom di Excel (mis. {{kota}}, {{produk}}).
  • Selalu Export Numbers Only / cek ulang daftar sebelum blast massal.

5. Lisensi & aktivasi

  • Kode lisensi format XXXX-XXXX-XXXX-XXXX didapat dari admin/panel.
  • Buka About > Licence untuk melihat sisa masa aktif dan tombol De-Activate.
  • 1 lisensi = 1 PC (terikat HWID). Pindah PC: minta admin cabut (revoke) HWID lama di panel, lalu aktivasi ulang di PC baru.
  • Butuh bantuan: Pandusolusi.com — WhatsApp 6281296052010.
